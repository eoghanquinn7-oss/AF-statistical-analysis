# AF Senescence Transcriptomic Analysis

# Overview
This project investigates gene expression differences between atrial fibrillation (AF) and sinus rhythm (SR), with a focus on senescence-associated mechanisms.

# Methods
- Differential expression analysis (Two sample t-test with FDR correction)
- Principal Component Analysis (PCA)
- Visualisation (Volcano plot, heatmap, violin plot)
- Senescence gene overlap analysis
- Pathway enrichment analysis (g:Profiler)

# Dataset
GSE79768 (Gene Expression Omnibus)

# Tools
- R (RStudio)
- Biocmanager
- GEOquery
- dplyr
- ggplot2
- gprofiler2
